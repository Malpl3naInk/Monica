- **A1 · 模板入口**：仅全局新建或主动更换模板时显示。从密码/笔记列表新建直接采用对应模板；没有新增必经向导。
- **A2 · 大标题与表单内模板**：顶栏只保留返回、收藏、更多。模板选择在新建密码大标题下，随表单滚动；下滑后的标题状态见 A3。模板不是存储类型限制。
- **A3 · 多笔记与内容选择**：同一项目草稿内的追加区。笔记可反复添加，点其中一篇进入 C4；下面的内容选择区内联展开，不是新数据库或绑定面板。
- **A4 · 一个项目，六份内容**：最终组件目录共六份：登录、OTP、两篇笔记、SSH、API Token。每份有稳定 ID；只有一个原始项目。三点菜单只操作对应内容。
