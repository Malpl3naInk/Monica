在“接入已有数据”步骤顶部增加入口，沿用现有操作卡片、分组圆角和 12dp 两侧留白。“从其他应用导入”打开应用标签，“手动导入文件”打开文件标签，目标数据库仍由用户选择。

导入页压入当前导航栈；返回后保留初始化步骤、预设和已保存的配置。正常导入、取消来源应用及返回均不把初始化标记为完成。F-Droid 不展示系统凭据交换入口。

验证（2026-09-17）：Debug 与 AndroidTest APK 构建通过。在公共 Android 32 模拟器上检查了原生页面渲染；应用入口默认打开 Apps，系统返回回到第六步；文件入口默认打开 Files，取消系统文件选择后仍留在导入页，点击页面返回后恢复第六步及原滚动位置。本轮验证范围为入口与导航，未执行新的跨应用凭据迁移。
